# Creatify.ai AI Avatar Lipsync Integration

## 1. Introduction

This integration allows you to generate AI avatar lipsync videos using the Creatify.ai API through the GraphCompose platform.

Core Features:
- Generate videos with a single avatar speaking from text or audio.
- Generate videos with multiple avatars in sequence.
- Asynchronous task handling (submit task, poll status, get result).

## 2. Authentication

Authentication uses Creatify API credentials.

- **Credentials Required:**
    - `apiId`: Your Creatify X-API-ID
    - `apiKey`: Your Creatify X-API-KEY
- **How to Pass:** Include `apiId` and `apiKey` in the JSON request body for all endpoints (`/create`, `/multi-avatar/create`, `/status`).
- Obtain credentials from your [Creatify account settings](https://app.creatify.ai/settings/api-keys) after enabling API access.

## 3. Available Endpoints

### Lipsync

- `POST /nodes/creatify/lipsync/create` - Initiates a task to create a single avatar video.
- `POST /nodes/creatify/lipsync/multi-avatar/create` - Initiates a task to create a video with multiple avatars.
- `POST /nodes/creatify/lipsync/status` - Queries the status of an ongoing or completed task.

## 4. Workflow (Asynchronous)

1.  **Submit Task:** Send a POST request to `/nodes/creatify/lipsync/create` or `/nodes/creatify/lipsync/multi-avatar/create` with authentication and video parameters.
2.  **Get Task ID:** If successful (200 OK), the response will contain a `taskId`.
    ```json
    {
        "success": true,
        "data": { "taskId": "YOUR_UNIQUE_TASK_ID" }
    }
    ```
3.  **Poll Status:** Periodically send a POST request to `/nodes/creatify/lipsync/status` including your `apiId`, `apiKey`, and the `taskId` obtained in step 2.
4.  **Check Status:** Examine the response from the `/status` endpoint. The `status` field will indicate the progress:
    - `submitted`: Task received but not yet started.
    - `processing`: Video generation is in progress.
    - `succeed`: Video generation completed successfully.
    - `failed`: Video generation failed.
5.  **Get Result:** If the status is `succeed`, the generated video URL will be in the `resultUrl` field of the `/status` response.
    ```json
    {
        "success": true,
        "data": {
            "taskId": "YOUR_UNIQUE_TASK_ID",
            "status": "succeed",
            "resultUrl": "https://video-output-url...",
            // ... other fields from Creatify ...
        }
    }
    ```
6.  **Handle Failure:** If the status is `failed`, check the `statusMessage` field for details about the error.

## 6. Error Handling

- **Task Creation:** Errors during task submission (invalid parameters, authentication failure, Creatify API issues) will result in a 500 status code response from the create endpoints.
- **Task Status:**
    - If the task itself failed during processing on Creatify's side, the `/status` endpoint will respond with a 200 OK, but the `status` field in the data will be `failed`, and `statusMessage` will contain the error details.
    - If querying the status fails (e.g., invalid `taskId`, authentication error), the `/status` endpoint itself will respond with a 500 status code.

#### Example Error Response (from `/create` endpoint)

```json
{
    "success": false,
    "message": "Failed to create single lipsync task: Creatify API Error (createSingleLipsyncTask): Invalid parameters (Status: 400)",
    "error": "Creatify API Error (createSingleLipsyncTask): Invalid parameters (Status: 400)"
}
```

## 7. Additional Notes

- You can find available `avatar_id` and `voice_id` values using the Creatify API or dashboard.
- Consider using the `callback_url` parameter in the create requests to receive status updates via webhook instead of polling the `/status` endpoint.
- Refer to the official [Creatify API Documentation](https://creatify.mintlify.app/api-reference/getting-started) for more details on parameters and capabilities.
