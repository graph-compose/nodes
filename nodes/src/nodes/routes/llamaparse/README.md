# LlamaParse Integration (SDK Approach)\n\n## 1. Introduction\n\nThis integration allows you to parse documents (like PDFs) into structured formats (Markdown or Text) using the LlamaParse service from LlamaIndex via their TypeScript SDK.\n\nCore Features:\n- Parses documents provided via a public URL.\n- Returns the parsed content directly in the selected format.\n- Uses the official `llamaindex` SDK.\n\n**IMPORTANT:** This node uses the LlamaParse SDK's `loadData` method, which waits for the entire parsing process to complete. **This may lead to timeouts** for very large or complex documents due to typical cloud function execution limits. Use with caution for potentially long-running parsing tasks.\n\n## 2. Authentication\n\nAuthentication uses a LlamaCloud API Key.\n\n- **Credentials Required:** LlamaCloud API Key (starts with `llx-`).\n- **How to Pass:**\n    1. Include the API key in the `apiKey` field within the JSON request body for the `/parse` endpoint.\n    2. **Crucially, the execution environment running this node *must* be configured to read this `apiKey` and set the `LLAMA_CLOUD_API_KEY` environment variable before the LlamaParse SDK is invoked.** The SDK relies solely on this environment variable.\n- Obtain your API keys from the [LlamaCloud Settings](https://cloud.llamaindex.ai/settings/keys).\n\n## 3. Available Endpoints\n\n### Parsing\n\n- `POST /nodes/llamaparse/parse` - Downloads a file from a URL, parses it using LlamaParse SDK, and returns the content.\n\n## 4. Workflow (Synchronous - SDK `loadData`)\n\n1.  **Submit Request:** Send a POST request to `/nodes/llamaparse/parse` with your `apiKey`, the `fileUrl` of the document, and optionally the desired `resultFormat` (`markdown` or `text`).\n2.  **Process Request:**\n    - The node downloads the file from `fileUrl` to temporary local storage.\n    - It initializes the `LlamaParseReader` from the `llamaindex` SDK.\n    - It calls `reader.loadData()` with the temporary file path.\n    - The SDK handles uploading to LlamaParse and waits for the parsing to complete.\n    - The node extracts the parsed text content.\n    - The temporary file is deleted.\n3.  **Receive Result:** If successful (200 OK), the response is a JSON object containing the `parsedContent`.\n    ```json\n    {\n        \"success\": true,\n        \"data\": {\n            \"parsedContent\": \"# Parsed Markdown Content\\\\n\\\\nThis is the content...\",\n            \"metadata\": { \"file_path\": \"/tmp/llamaparse-input-...\_pdf\" }\n        }\n    }\n    ```\n4.  **Handle Failure:** If any step fails (download error, SDK error, LlamaParse API error, timeout), the endpoint responds with a 500 status code and error details.\n\n## 5. Request and Response Examples\n\n#### Example Request\n\nPOST /nodes/llamaparse/parse\n\n```json\n{\n    \"apiKey\": \"llx-YOUR_LLAMACLOUD_KEY\",\n    \"fileUrl\": \"https://arxiv.org/pdf/2307.09288.pdf\",\n    \"resultFormat\": \"markdown\"\n}\n```\n\n#### Example Response (Success)\n\n```json\n{\n    \"success\": true,\n    \"data\": {\n        \"parsedContent\": \"# Llama 2: Open Foundation and Fine-Tuned Chat Models\\\\n\\\\nAbstract\\\\nIn this work, we develop and release Llama 2... (rest of markdown content)\",\n        \"metadata\": { \"file_path\": \"/tmp/llamaparse-input-....pdf\" }\n    }\n}\n```\n\n## 6. Error Handling\n\n- Errors during file download, SDK execution (which includes communication with LlamaParse API), or if the SDK call times out, will result in a 500 status code response.\n- Ensure the `LLAMA_CLOUD_API_KEY` environment variable is correctly set for the execution environment.\n\n#### Example Error Response\n\n```json\n{\n    \"success\": false,\n    \"message\": \"Failed to parse document: LlamaParse processing failed: Error calling LlamaParse: [Original LlamaParse/SDK Error Message]\",\n    \"error\": \"LlamaParse processing failed: Error calling LlamaParse: [Original LlamaParse/SDK Error Message]\"\n}\n```\n\n## 7. Additional Notes\n\n- Remember to install the necessary dependencies: `llamaindex`, `dotenv`, `axios`.\n- The SDK approach waits for completion, be mindful of potential timeouts for long jobs.\n- Refer to the [LlamaParse Documentation](https://docs.cloud.llamaindex.ai/llamaparse/getting_started) for more details on supported file types and features.\n
